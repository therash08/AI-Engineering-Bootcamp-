# ⚙️ Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/therash08/AI-Engineering-Bootcamp-.git
```

## 2. Navigate to the Repository

```bash
cd AI-Engineering-Bootcamp-
```

## 3. Create a Virtual Environment

### Windows

```bash
python -m venv .venv
.venv\Scripts\activate
```

### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
```

## 4. Install Common Dependencies

```bash
pip install numpy pandas matplotlib scikit-learn jupyter
```

For Deep Learning, Computer Vision, and NLP experiments, additional libraries may be required:

```bash
pip install torch torchvision opencv-python ultralytics transformers sentence-transformers
```

## 5. Start Jupyter Notebook

```bash
jupyter notebook
```

Then open any `.ipynb` notebook and explore the implementation.
